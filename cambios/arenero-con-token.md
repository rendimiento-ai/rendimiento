- **Coding agent:** the `run` tool's sandbox clones a private repository again: it gets the app's installation token, as a run's steps do, instead of cloning anonymously ("could not read Username for 'https://github.com'"). It clones from the app's forja (GitLab and Bitbucket apps no longer clone from github.com), and before the agent's first commit it starts from the commit its branch started from.
- **Fixes:** declared fixes (the coding agent's `run_fix`, the run page's button and Renovate's branches) clone with the app's installation token and from its forja too, so they work on private repositories and on GitLab and Bitbucket apps.
