- **Merging:** A branch whose change touches a folder no step builds or tests (a `mobile/` app beside services in `api/` and `web/`) is no longer merged by itself. Its run still passes, but rendimiento merges it only on a person's yes (Merge this branch, or an accepted encargo; an open pull request is not the yes for it), and its GitHub check concludes Action required instead of success, saying which paths no step tests ("No step builds or tests `mobile/`: a person must merge this"), so Renovate's automerge waits too. The person's yes turns the check green. Root steps, `rendimiento.yaml`, Markdown, licences and git/editor/Renovate settings count as tested.
- **UI:** The run's page says which paths of the change no step tested, and that a person must merge it.
- **Database:** Migration 0054 adds `runs.untested` (text array, empty by default).
