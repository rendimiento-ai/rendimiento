- **Previews:** a copy (a pull request's, or a short one for checks en seco) now gets each secret `X` its app reads from the app's preview variant `X-preview`, copied into the copy's namespace as `X` with the same type and keys. Production's `X` is never copied: without `X-preview` the copy runs without `X`. The controller keeps them in sync on every reconcile of the copy and at once when an `X-preview` is saved or deleted, and the copy's pods roll when they change. On a computer, copies' containers read `X-preview` too, taking an edit at their next refresh.
- **Previews:** on an app's Settings page, each secret shows its **Preview** variant (whether it exists, its keys, never values), set the same way by administrators; saving it does not restart the app. `GET /api/apps/{app}/preview-secrets` lists, by name, the secrets the app's copies run without.
- **Secrets:** the app's own tests' `secretEnv` (`tests:`) now counts among the app's secrets, so it can be set on the Settings page.
