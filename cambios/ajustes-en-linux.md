- **One computer:** on Linux, rendimiento's settings now have a place that lasts: the service reads `~/.config/rendimiento/env` (one `NAME=value` per line, winning over the service's own values), which the installer makes once, with a header saying how, and never writes again; run the installer once more to get it on an existing install. After a change, `systemctl --user restart rendimiento`.
- **One computer:** the Environment page is there for the platform's administrators on a computer too: the Version card, with its switch for installing fix releases by itself, and which settings file this computer reads (or the WSL distribution's `/etc/rendimiento/env`) with the command that restarts it.
